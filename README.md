# F1 Telegram-бот

Бот собирает русскоязычные новости и статьи о Формуле 1 из RSS-источников, анализирует их на дублирование контента и в течение дня публикует в канал 4–5 самых актуальных статей.

## Как это работает

1. **Сбор** — каждые `COLLECT_INTERVAL_MIN` минут бот опрашивает RSS-фиды параллельно (aiohttp).
2. **Фильтрация** — статьи отбираются по словарю ключевых слов Формулы 1 (пилоты, команды, гран-при, трассы и т.д.).
3. **Дедупликация** — для каждой новой статьи считается схожесть с последними N статьями: Jaccard по триграммам слов + символьные n-граммы заголовка. Если схожесть выше `DUPLICATE_THRESHOLD` — статья помечается дубликатом и не публикуется.
4. **Ранжирование** — актуальность = 55% свежесть (экспоненциальное затухание ~12 ч) + 30% авторитет источника + 15% содержательность («горячие» темы, длина текста).
5. **Фото к посту** — картинка берётся из RSS (`media:content`/`enclosure`), а если её нет — со страницы статьи (og:image). Если фото недоступно, пост уходит текстом.
6. **Публикация** — 20 раз в день (по `POST_TIMES`) в канал уходит одна самая актуальная статья. Формат поста: краткий заголовок + подробная выжимка (полное описание из RSS, для Google News — meta description со страницы), скрытая спойлером `<tg-spoiler>` и раскрывающаяся по тапу; внизу источник, время и ссылка.

## Источники

| Источник | URL |
|---|---|
| Чемпионат (F1) | `https://www.championat.com/rss/news/auto/f1/` |
| Autosport.ru | `https://autosport.com.ru/rss.xml` |
| F1News.ru | `https://www.f1news.ru/export/news.xml` |
| Motor.ru | `https://motor.ru/export/rss/f1` |
| Google Новости (F1, RU) | агрегатор `news.google.com` |

Список источников редактируется в `bot/collector.py` (переменная `SOURCES`), где третье число в кортеже — вес источника при ранжировании.

## Установка

```bash
cd f1-telegram-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните .env: BOT_TOKEN и CHANNEL_ID
```

## Запуск

```bash
python main.py
```

Демон: `nohup python main.py > bot.log 2>&1 &` или через systemd / pm2.

## Проверка без Telegram

Запускает реальный сбор, дедупликацию и показывает топ статей, ничего не постит:

```bash
python scripts/smoke_test.py
```

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота от @BotFather |
| `CHANNEL_ID` | — | `@channel` или `-100xxxxxxxxxx` |
| `ADMIN_CHAT_ID` | — | если задан, в этот чат придёт дневной отчёт в 23:50 |
| `TZ` | `Europe/Moscow` | часовой пояс для расписания |
| `COLLECT_INTERVAL_MIN` | `15` | период сбора, минуты |
| `POST_TIMES` | 20 значений, 07:30–21:45 каждые 45 мин | время публикаций |
| `MAX_AGE_HOURS` | `30` | статьи старше не публикуются |
| `DUPLICATE_THRESHOLD` | `0.62` | порог схожести для дублей |
| `KEEP_TOKENS_FOR` | `300` | сколько последних статей сравнивать |
| `HTTP_TIMEOUT` | `20` | таймаут запроса к фиду, сек |
| `MAX_ITEMS_PER_FEED` | `50` | сколько записей брать с одного фида |
| `LOG_LEVEL` | `INFO` | уровень логирования |
| `SSL_VERIFY` | `true` | `false` — отключить проверку SSL (только для отладки) |

## Требования

- Python 3.11+
- Бот должен быть администратором канала и иметь право публиковать сообщения.
